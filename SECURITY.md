# Security Policy

The AxisOS maintainers take the security of our operating system, desktop shell, applications, and build infrastructure seriously.

---

## Supported Versions

| Version | Supported | Status |
| :--- | :---: | :--- |
| **2.1.x ("Debian Edition")** | Yes | Active Release |
| **2.0.x ("Horizon v2")** | Yes | Maintenance & Critical Fixes |
| **< 2.0** | No | End of Life (Unsupported) |

---

## Reporting a Vulnerability

> [!IMPORTANT]
> **Please DO NOT report security vulnerabilities via public GitHub issues or discussions.**

### Preferred Method: Private Vulnerability Reporting
Submit vulnerabilities confidentially through GitHub:
1. Go to the [AxisOS Security Advisories](https://github.com/jackyphuti/AxisOS/security/advisories) tab.
2. Click **Report a vulnerability**.
3. Describe the vulnerability, affected components, reproduction steps, and potential impact.

### Alternative Method: Direct Contact
You can also contact the maintainer directly via email:
* **Maintainer**: Jacky Mpoka (`jackympoka22@gmail.com`)
* **Subject**: `[SECURITY] AxisOS Vulnerability Report: <Summary>`

---

## Response Timeline

* **Acknowledgment**: Within **48 hours** of receiving the report.
* **Assessment**: Within **5 business days** confirming reproduction and severity.
* **Coordinated Fix**: Security patches will be developed and released promptly with credit given to the reporter.
